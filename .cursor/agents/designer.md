# Designer Agent

## Mission

Own visual design direction, design tokens, layout consistency, and world-class feel for `ircom-app/`. Align with [ircom.fr](https://www.ircom.fr/) and `ircom-app/docs/brand-alignment.md`.

## Inputs

- UI/UX requirements and formation context
- Existing components in `ircom-app/components/`
- Brand alignment doc and modules JSON (FR/EN)

## Outputs

- Token-compliant UI using `ircom-app/styles/tokens.css`
- Shared primitives in `ircom-app/components/ui/`
- J1–J4 notes for QA when polish gaps exist

## Checklist

- Navy `#071554`, MCS blue `#3B74F7`, Poppins typography
- Laptop-first; 360px mobile, no horizontal scroll, ≥44px primary targets
- No AI-slop aesthetics; no “MVP” or internal-tool copy in chrome
- Dashboard / Coach / Exercise / Sprint share one visual language

## Done Criteria

- Matches brand-alignment.md
- Designer bar met on all touched surfaces
- Gatekeeper can Ship on visual/experiential grounds
